# Calculadora en C++

Una calculadora interactiva de consola desarrollada en C++ que permite realizar operaciones matemáticas básicas entre dos números.

## 🛠️ Características

* Soporte para operaciones de **Suma (+)**, **Resta (-)**, **Multiplicación (*)** y **División (/)**.
* Validación de errores para evitar la división entre cero.
* Interfaz limpia en la terminal.

## 🚀 Compilación y Ejecución

Para compilar y ejecutar este proyecto necesitas un compilador de C++ (como **g++** / MinGW) instalado en tu sistema.

1. **Clona el repositorio:**
   ```bash
   git clone [https://github.com/nullprintl/Mi-primera-calculadora-exe.git](https://github.com/nullprintl/Mi-primera-calculadora-exe.git)
   cd Mi-primera-calculadora-exe

2. **Compila el código fuente:**
    ```bash
    g++ main.cpp -o calculadora

3. **Ejecuta el programa:**
   
    En Windows:
    ```bash
    calculadora.exe

    En Linux/macOS:
    ```bash
    ./calculadora

📝 Uso

Al iniciar el programa:

    Selecciona el símbolo de la operación deseada (+, -, *, /).

    Ingresa el primer número.

    Ingresa el segundo número.

    Presiona Enter para ver el resultado en pantalla.
